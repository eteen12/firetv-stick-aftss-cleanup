# Debloat list for the Amazon Fire TV Stick AFTSS (codename sheldon, sold as Fire TV Stick Lite 2020)
# on Fire OS 7.7.1.7 (PS7717/5741), Android 9 / SDK 28.
#
# Format: one package name per line. Everything after a "#" is a comment.
# debloat.sh runs `pm disable-user --user 0 <pkg>` for each line (disabled, never uninstalled);
# restore.sh runs `pm enable --user 0 <pkg>`. Comment out any line you want to keep.
#
# Sections 1 to 4 are derived from the cleanyourtv list
# examples/amazon-fire-tv-stick-lite-2020/debloat.txt at https://github.com/Gathin23/cleanyourtv
# Copyright (c) 2026 Gathin, MIT License (full notice in LICENSE).
# Section 5 (extras) and section 6 (optional) were added for this repo and tested on the same stick.
#
# Kept on purpose (not in this list): com.amazon.tv.launcher, com.amazon.tv.settings.*, com.amazon.venezia
# (Appstore), com.amazon.tv.ime (keyboard), remote/Bluetooth services, OTA updates, Alexa voice search
# (com.amazon.vizzini, aria, cardinal, ivona TTS, tcomm), Prime Video (com.amazon.firebat, com.amazon.tv.support),
# casting (cast.sink, dialservice, awvflingreceiver, whisperplay, whisperlink), profiles
# (com.amazon.prism.android.service), com.amazon.tv.oobe (needed for a factory reset), screensaver,
# accessibility (com.amazon.logan).
#
# Protected on this build. Fire OS refuses both `pm disable-user` and `pm suspend` for these, so they are
# listed only as comments. privacy-dns.sh blocks what they phone home to instead:
#   com.amazon.minerva.client.api, com.amazon.device.logmanager, com.amazon.device.crashmanager,
#   com.amazon.diode, com.fireos.usagestats.proxy, com.amazon.ftvads.deeplinking, com.amazon.tv.csapp,
#   com.amazon.tv.launcher
